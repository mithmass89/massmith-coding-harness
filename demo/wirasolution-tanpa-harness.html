Risiko Tanpa Harness

  • Perintah --no-verify, rm -rf /, drop table bisa dieksekusi
  • api_key dan Bearer token bocor ke log / transcript
  • File berubah tanpa test tidak ada peringatannya
  • Tidak ada system prompt disiplin — diff besar tanpa review
