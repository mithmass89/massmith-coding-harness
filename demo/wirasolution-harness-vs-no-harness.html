Coba Guardrail-nya Langsung.

Ini fungsi validateCommand() yang sama dengan core harness — jalan 100% di browser Anda. Ketik perintah berbahaya dan lihat diblokir, atau perintah aman dan lihat lolos.

Playground Guardrail

Masukkan perintah shell. Mode harness AKTIF — sinkron dengan toggle di atas.

--no-verify rm -rf / push --force ls -la npm run test

Kenapa Pakai Harness?

Tanpa harness, agent coding bisa jalanin perintah merusak tanpa rem. Dengan Massmith, setiap perintah dicek dulu:

  • Blok --no-verify, rm -rf /, drop table, git push --force
  • Redaksi api_key, Bearer token, private key otomatis
  • Peringatan kalau file berubah tanpa file test pendamping
  • System prompt: diff kecil, reviewable, wajib test/typecheck/lint
